02 Quest: instalar a tradução

  1. Feche o jogo

    O instalador precisa mexer nos arquivos do jogo, então ele não pode estar aberto.

  2. Baixe e extraia o zip

    Clique com o botão direito no zip → Extrair tudo..., abra a pasta Traducao_PTBR_... e execute o programa. Não precisa de administrador. Se o Windows mostrar "O Windows protegeu o computador", clique em Mais informações → Executar assim mesmo. Veja na seção de segurança por que esse aviso aparece.

  3. Clique em "Instalar tradução"

    O jogo é encontrado sozinho pela Steam. Se não for, use Procurar... e aponte a pasta do jogo.

  4. Jogue!

    Para voltar ao original: abra o instalador e clique em Desinstalar, ou use Verificar integridade dos arquivos na Steam.

🎮 Side quest: Steam Deck

Baixe o zip Steam Deck / Linux do jogo e vá para o Modo Desktop (botão Steam → Ligar/Desligar → Mudar para a área de trabalho). Clique com o botão direito no zip → Extrair aqui, abra a pasta e dê dois cliques em Instalar.sh → Executar. O jogo é achado sozinho, na memória interna ou no cartão SD. Depois é só voltar ao Modo de Jogo. Para remover, rode o Instalar.sh de novo e escolha Desinstalar.

03 Por que confiar

Baixar programas da internet exige confiança. Por isso cada etapa aqui pode ser conferida por qualquer pessoa.

📜

Código 100% aberto

O instalador e todas as traduções estão no GitHub. Dá para ler cada linha antes de rodar.

🤖

Build automático no GitHub

Os executáveis são gerados pelo GitHub Actions direto do código público, não no PC de alguém. O log de cada build fica visível.

🔏

Atestação de origem

Cada arquivo recebe uma atestação assinada (Sigstore) que prova de qual commit e de qual build ele saiu.

#️⃣

Hash SHA-256

Toda versão publica o SHA-256 dos arquivos. Se um byte mudar, o hash muda.

🛡️

Análise no VirusTotal

Os arquivos são enviados ao VirusTotal (mais de 60 antivírus) e o link do resultado fica nas notas da versão.

↩️

Desinstalação limpa

Nada é apagado. O instalador guarda um backup e a desinstalação devolve o jogo ao original, byte a byte.

"O Windows protegeu o computador"? Calma, a gente explica!

Quando você abre a tradução, o Windows pode mostrar um aviso de "editor desconhecido". Isso acontece porque o programa não tem uma assinatura digital, um certificado que a Microsoft reconhece e que pode passar de R$ 1.000 por ano. Para um desenvolvedor sozinho, que faz tudo de graça, esse custo ainda não cabe no bolso. 🥲

Para compensar, cada arquivo é analisado no VirusTotal, que passa ele por mais de 60 antivírus ao mesmo tempo, e todo o código fica aberto no GitHub para quem quiser conferir.

1

Confira no VirusTotal

No card do jogo, clique no botão azul 🛡️ VirusTotal. Você vai ver a lista de antivírus e quantos acharam algum problema. O nosso está em 0.

2

Abra a tradução

Se aparecer o aviso azul do Windows, clique em Mais informações e depois em Executar assim mesmo.

Para quem entende de tecnologia: verificação avançada

Compare o SHA-256 do arquivo com o publicado nas notas da versão (PowerShell):

Get-FileHash .\The_Wolf_Among_Us_Traducao_PTBR.zip -Algorithm SHA256

Confirme que o arquivo foi gerado pelo GitHub Actions a partir deste repositório (precisa do GitHub CLI):

gh attestation verify .\The_Wolf_Among_Us_Traducao_PTBR.zip --repo DangoHub/traducoes-ptbr

05 FAQ

Preciso ter o jogo original?

Sim. A tradução só substitui os textos e não inclui nenhum arquivo do jogo. Funciona com a versão da Steam indicada em cada card.

O jogo atualizou e a tradução sumiu. E agora?

Rode o instalador de novo. Se a atualização trouxe texto novo, ele aparece em inglês até sair uma versão nova da tradução.

Funciona no Steam Deck?

Sim! Cada jogo tem um zip Steam Deck / Linux com o instalador Instalar.sh. Ele roda no Modo Desktop, não precisa instalar nada (o SteamOS já traz tudo que ele usa) e acha o jogo na memória interna ou no cartão SD.

Por que no Garden of Witches eu escolho "English"?

O jogo não tem opção de português, então a tradução ocupa o lugar do inglês.

Algumas falas do The Wolf Among Us estão sem legenda.

Isso acontece no jogo original: cerca de 756 falas (como as de "Anteriormente em...") só têm áudio, sem texto, até em inglês.

Achei um erro de tradução. Como aviso?

Abra uma issue no GitHub com um print ou o texto da fala.

Isso é pirataria?

Não. É uma tradução de fãs, sem fins lucrativos, que exige o jogo comprado. Nenhum arquivo do jogo é distribuído.
